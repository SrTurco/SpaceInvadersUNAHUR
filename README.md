# Space Invaders UNAHUR

Juego arcade hecho con Godot 4.7.2 .NET y C#. Para abrirlo, instalar Godot con soporte .NET y el SDK de .NET 8, importar `project.godot`, compilar y ejecutar con F5.

Controles: Enter para jugar, T para el tutorial, flechas para moverse, Espacio para disparar o continuar y Esc para pausar.

La nodriza final tiene escoltas que orbitan, ataques por turnos y un rayo maestro anunciado. La victoria se consigue al derrotar a la nodriza.

La [guía del proyecto](docs/GUIA_PROYECTO.md) explica cómo abrirlo, cómo se conectan las escenas y los scripts, cómo modificar cada mecánica y cómo probar o exportar los cambios. Incluye una tabla de cambios rápidos y soluciones a problemas frecuentes.
